# Research Cycles

Create Cycle directories with a two-digit, monotonically increasing sequence, for example `01-first-chain` and `02-decoder-capacity`. The sequence records creation order, not priority or completion.

Each Cycle should reduce one primary scientific uncertainty and contain `question.md`, `experiment.md`, `deliverables.md`, `tasks.md`, `status.md`, and `decisions.md`. Execution publishes decision-bearing artifacts beneath `results/`.
