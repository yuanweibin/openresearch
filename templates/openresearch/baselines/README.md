# Baseline catalog

Baselines are reusable comparison assets, not research Cycles. Each baseline preserves a
published or otherwise authoritative setup, the evidence extracted from that source, this
project's reproduction, and clearly labelled extensions under the same setup.

Create one stable directory per source/setup family, for example
`baselines/tgv-reissmann-2021/`. Do not number Baselines by Cycle order.
